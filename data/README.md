# Data sources and limitations

- Open-Meteo docs: https://open-meteo.com/en/docs
- Historical weather: https://open-meteo.com/en/docs/historical-weather-api
- Terms/pricing: https://open-meteo.com/en/pricing
- Pune coordinates used: approximately 18.52, 73.86.
- Candidate Pune municipal datasets: https://data.opencity.in/dataset/?organization=pune-municipal-corporation
- BattLeDIM benchmark: https://zenodo.org/records/4017659

Inspect each file's publisher, date coverage, columns, units, and licence before use.
The bundled sensor records are synthetic UI examples, not BattLeDIM measurements.
Do not call a weather score a measured water shortage or a synthetic anomaly a Pune leak.
